Put your screenshots and a short GIF here (for example `android.png`, `ios.png`, `demo.gif`)
and they will show up in the main README.

Android: Android Studio > Running Devices > camera icon, or `adb exec-out screencap -p > android.png`.
iOS: Simulator > File > Save Screen (Cmd+S). For a GIF, record with `xcrun simctl io booted recordVideo demo.mov` and convert it.
